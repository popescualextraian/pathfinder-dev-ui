# Better menu structuring (backlog item 10) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the sidebar's "Show" switch with grouped, icon-led navigation (Work / Automate / Team) and move the repository filter under Tasks.

**Architecture:** Navigation is data: `Sidebar` builds a list of groups of items from props and renders only visible items/groups. A new `NavItem` view renders one item (icon, label, optional count badge). `RepositoryList` keeps its logic but renders as an indented sub-list under the Tasks item, only while Tasks is active. Frontend only.

**Tech Stack:** React, TypeScript, CSS modules with tokens from `theme.css`, jest + Testing Library (`frontend/test`), Playwright (`e2e/`).

**Spec:** `docs/superpowers/specs/10-design.md` (mockup: `docs/superpowers/specs/assets/10-mockup.png`; ignore its "Runs"/"+ New agent run" labels, they stay "Tasks"/"+ New task").

## Global Constraints
- Name stays "Tasks"; button stays "+ New task".
- Groups and order: **Work** = Backlog, Tasks; **Automate** = Workflows; **Team** = none yet. A group with no visible item is not rendered. No placeholders for Schedules/Colleagues/Settings.
- Backlog item only when `backlogEnabled`; Workflows only when `workflowsEnabled` (as today). Backlog off: only Tasks shows.
- Item text 15px; section labels keep the existing `.kicker` style; active item keeps the red inset bar and `aria-current="true"`.
- Icons: inline SVG components in the repo, `aria-hidden`, no icon library. CSS only via `theme.css` variables. No external fonts/CDNs.
- Accessible name of each nav button is exactly its label ("Tasks", "Backlog", "Workflows"); count badges are `aria-hidden`.
- Routes/URLs and `useRoute` are unchanged. No backend/API change.

## Review Focus
- Backlog off and workflows on (or the reverse): no empty group label, Tasks still reachable.
- Zero repositories: Tasks sub-list still shows "All repositories (0)".
- Selecting a repository while on Backlog/Workflows: the sub-list is hidden there, and clicking Tasks returns to the tasks view with the previously selected repository kept (the route keeps `repository`).
- A large count (e.g. 1234) in the badge does not wrap or push the label.
- Keyboard: every item is a focusable button with a visible focus outline.
